# pufETH Conversion Rate Tracker

A full-stack application that tracks and visualizes the pufETH conversion rate over time.

## Project Structure

- `frontend/` - React + Vite frontend application
- `backend/` - Node.js microservice for tracking pufETH conversion rates

## Tech Stack

### Frontend
- Vite
- React
- Material UI
- TypeScript

### Backend
- Node.js
- Express
- Web3.js/Ethers.js (for Ethereum interaction)
