Puffer FullStack Take-Home Coding Assignment: pufETH Conversion Rate Tracker

## Objective

Build a microservice that tracks the pufETH conversion rate and a frontend to display the changes over time.

## Background

pufETH is one of Puffer's main products. More information can be found at docs.puffer.fi.

> https://docs.puffer.fi/

## Requirements:

1. Create a microservice that tracks the pufETH conversion rate.
2. Develop a frontend that displays the changes of the pufETH conversion rate over time.
3. The conversion rate is calculated as `totalAssets()` / `totalSupply()`.
4. These functions are available in the PufferVaultV2 contract at address: 0xD9A442856C234a39a81a089C06451EBAa4306a72.

> 0xD9A442856C234a39a81a089C06451EBAa4306a72

## Deliverables

5. A public GitHub repository containing your project.
6. Clear instructions in the README on how to run/deploy the microservice and frontend.
7. Be prepared to demo the project during the interview.

## Guidelines

● You may use any resources, including open-source code and AI tools.
● There are no restrictions on the tech stack used.
● You can include any additional features or visualizations you think would be valuable.

## Time Limit

You have 3 days to complete this assignment.
Interview Follow-up
During the interview, be prepared to: 8. Demo your project. 9. Discuss your development process and system architecture. 10. Explain any challenges you faced and how you overcame them. 11. Propose next steps for improving the application if given more time.

    Note to Candidates
    We are looking for driven developers. The scope of this task is designed so that a developer capable of asking the right questions can deliver this regardless of their web3 experience. Don't hesitate to research, learn, and apply new concepts as needed.
